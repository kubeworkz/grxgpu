# PTA FPGA Stand-In Platform Options

**Status:** Engineering comparison for decision preparation; no platform selected and no procurement authorization.
**As of:** 2026-10-18
**Owner:** Dave Cook, PTA technical owner. Stand-in implementation and board decision owners remain to be assigned.

## Executive recommendation

**Do not approve a platform purchase or freeze an FPGA part from this review alone.** The strongest candidate to investigate for fidelity to the recorded first-board transport is the **Altera Agilex 7 I-Series R-Tile Development Kit**, part `DK-DEV-AGI027-RA-B` / FPGA `AGIB027R29A1E1VB`. Altera documents R-Tile PCIe 5.0 x16 and CXL 1.1/2.0 capability for discrete accelerator use cases, and the kit guide confirms a production 2×R-Tile + 1×F-Tile board. That makes it the best documented technical lead, **not a verified/selected PTA solution**: we have not established the exact Altera CXL IP release and Type-1/CXL.cache feature set, build/license access, host compatibility, or orderability.

If immediate work only needs to implement and test the 128×64 arithmetic/control RTL **without** claiming the real module link, separate the targets: use a modest FPGA board with an accessible host/debug interface for a logic prototype, and keep CXL system integration blocked until the GRX930 root port and module link are verified. The dimensions describe 8,192 row/column positions; they do not define a physical PE count, arithmetic width, memory architecture or FPGA resource estimate. Platform fit must be measured from the actual implementation, not inferred from geometry.

## Requirements and boundary

The stand-in request calls for a deterministic logical 128×64 tile; a 64→16 FC3 operation; actual host-visible discovery and GEMM commands; `PTA_CAPS2[31]` set; FPGA endpoint activity over a real module link; exact seeded output comparison; repeatability, error recovery and a clean image/build record. The first-board GRXCP transport decision is **CXL 2.0 Type-1 over a PCIe 5.0 PHY from the GRX930 host**. GRXCP commit [`9667adec5e8f07a5415a2832a1622ee9c93d87ab`](https://github.com/kubeworkz/grxcp/commit/9667adec5e8f07a5415a2832a1622ee9c93d87ab), [`pta_board_transport.md`](https://github.com/kubeworkz/grxcp/blob/9667adec5e8f07a5415a2832a1622ee9c93d87ab/docs/designs/pta_board_transport.md) (blob `e76a3c6aa3cf1e66efaee23bc2ecb6c89bd42664`) says this is a design/model and explicitly says no module, root port or driver code exists. This is therefore a candidate assessment, not proof the full board can work.

A PCIe Gen5 transceiver, a PCIe endpoint, or a board with a Gen5 connector is **not by itself** a CXL Type-1 device. A compliant endpoint needs the appropriate CXL IP/protocol, cache-coherency behavior and host/root-port/software support. Confirm every link layer before making the chosen target a requirement.

## Recommended shortlist

1. **First choice to investigate: Agilex 7 I-Series R-Tile kit.** Request vendor confirmation that the exact production kit and installed device support the required CXL 2.0 Type-1 endpoint mode, CXL.cache operations required by the GRXCP queue, Quartus/IP release and license, endpoint reference design, reset/link training, and operating-system integration. Require a supported reference image plus exact constraints and known limitations.
2. **Fallback if the GRX930 host cannot support CXL:** pause the board-level CXL design and request a formal interface decision. Candidate alternatives must be compared against the actual GRX930 host and workload, not selected just because a card supports PCIe. Do not silently relabel plain PCIe DMA, CCIX, UCIe or a simulation link as CXL Type-1.
3. **Optional parallel logic-only prototype:** if the team has a U55C or Arty A7-100T already accessible, use it only for synthesizable tile/control experiments with a clearly different test interface (e.g. JTAG/UART/host test harness) and no claim of first-board module transport or CXL integration. Keep platform/tool choice separately identified from the selected system target.

## Decision gates before platform selection

- **G1 — Host:** identify exact GRX930 host/root-port/PHY part and prove PCIe Gen5 x16 electrical/protocol support, CXL.cache/Type-1 capability, firmware/boot discovery, and Linux driver support. Capture vendor documentation and a host-side capability report.
- **G2 — Endpoint/IP:** get written vendor confirmation for the exact FPGA part, CXL IP release, Type-1 device/cache operations, supported Quartus/Vivado version, licenses, reference design, and implementation restrictions. Distinguish CXL.io MMIO from CXL.cache data transfer.
- **G3 — Board/module:** show the selected endpoint board/carrier is electrically compatible with the GRX930 root port: connector, lane count, retimer/clocking, reset/sideband, power/thermal, enumeration and mechanical form factor. The stand-in can be separately addressable only if the complete physical path exists.
- **G4 — Implementation feasibility:** map the declared tile and queue to the part, run a clean synthesis/implementation on the exact tool release, retain LUT/BRAM/DSP and timing reports against approved targets, and produce a reproducible image hash. No generic “fits” claim before this check.
- **G5 — Software and behavior:** implement/verify discovery (`PTA_CAPS2[31]`), register/GEMM semantics, completion/error recovery and the seeded exact-output test over the actual link. Prove host ownership/ordering and observability; do not accept model-only success as hardware integration.
- **G6 — Availability and authority:** record named implementation/board owner, independent reviewer, vendor/reseller quote or on-hand asset record, tool/IP entitlement, funding/procurement authority and approved schedule before purchase or target freeze.

## Disposition

**Recommendation:** keep the platform field `not_selected`; advance Agilex 7 R-Tile to a vendor-and-host feasibility gate, not procurement. The critical unknown is not FPGA tile capacity but a complete, supported **GRX930 CXL 2.0 Type-1 endpoint path**. Record a new decision only after G1–G6 have evidence and the authorized owners approve the exact target.
