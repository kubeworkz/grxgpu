## Handling and status rules

This file is a public, redacted tracker only. Put restricted PDK collateral, contracts, quotes, account details, and supplier correspondence in approved access-controlled storage. Record only a reviewed vault record ID in the private working copy; do not add secrets, restricted URLs, license keys, or proprietary process details to this repository.

`Reported` means supplied by a project participant but not independently evidenced. `Unverified` means the required primary evidence has not been reviewed. `Blocked` means a named dependency prevents assessment. `TBA (deferred)` means a deferral has been proposed or approved; record the approval state explicitly. Every item needs a deferral ID, accountable role, re-entry trigger, affected gate, and latest resolution point. A proposed but unapproved deferral does not change the accepted target date: evidence remains due then and the gate remains blocking. `TBD` remains the placeholder for an unknown value in a planning model, such as a price or quantity. Neither label is evidence, acceptance, or a pass. Do not mark a row received, licensed, compatible, or done based on a directory, plan, verbal assumption, or flow script alone.
